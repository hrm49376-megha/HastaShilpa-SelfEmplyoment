# HastaShilpa – Self Employment Platform

A web-based platform designed to support and empower artisans, handicraft makers, and self-employed individuals by providing digital visibility for their products and services.

## 📌 Project Overview

HastaShilpa is a self-employment initiative focused on promoting handmade products, traditional crafts, and small-scale businesses. The platform helps artisans showcase their work, connect with customers, and improve their online presence.

## 🚀 Features

- 🛍️ Product showcase for handicrafts
- 👨‍🎨 Artisan profile management
- 📱 Responsive user interface
- 🔍 Search and filter products
- 🖼️ Product image gallery
- 📞 Contact and inquiry support
- 🌐 Easy navigation and clean design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Git & GitHub
